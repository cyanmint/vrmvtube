# VRM Models

This directory contains VRM models used in VRMVTube.

## Default Model

**cyanmint.vrm** - Default sample VRM model
- Source: https://t.gro-w.org/0eiqvMtmzM/cyanmint.vrm1.0.vrm
- Format: VRM 1.0
- This model is included as the default sample for testing and demonstration

## Adding Your Own Models

You can load any VRM 0.0 or VRM 1.0 model by:
1. Clicking "Load VRM Model" button in the app
2. Selecting your `.vrm` file from the file dialog

## VRM Specification

VRM is a 3D avatar file format for VR applications. Learn more at:
- https://vrm.dev/en/
- https://github.com/vrm-c/vrm-specification
